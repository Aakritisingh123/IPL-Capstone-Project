# 🏏 IPL Data Analysis Project

## 📌 Overview

This project is an **IPL Data Analysis Capstone Project** created using Python.  
The main objective of this project is to perform **Exploratory Data Analysis (EDA)** on IPL match data and extract meaningful insights using data visualization techniques.

---

## 🚀 Project Features

- Analyze IPL match records
- Find team-wise match performance
- Analyze toss decisions and match results
- Study winning patterns
- Analyze Player of the Match awards
- Find top-performing players
- Analyze venue-wise match statistics
- Create visualizations for better understanding

---

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
